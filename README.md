# PideYa - Pedidos a Domicilio

Aplicación web de entrega a domicilio estilo PedidosYa, desarrollada con HTML, CSS y JavaScript.

## Secciones de la aplicación
- **Inicio / Landing:** Presentación del servicio con tiempos estimados de entrega y acceso rápido al catálogo.
- **Categorías y Catálogo:** Filtrado por categorías (Todo, Comida rápida, Súper, Postres) con precios, tiempos de entrega, estado de envío y botones para agregar productos al pedido.
- **Asistente de Antojos (IA):** Recomendador interactivo que sugiere opciones según lo que escriba el usuario y permite pasar la sugerencia al formulario.
- **Formulario de Pedido:** Permite registrar solicitudes de entrega con nombre, teléfono, dirección y detalle del pedido.
- **Panel Admin:** Gestión de pedidos guardados en el navegador (`localStorage`), con opción para ver el historial y vaciar registros.
